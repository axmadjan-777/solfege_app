# Шаблон одной задачи

Помогает менеджеру задать результат, границы и способ приёмки. Постоянный процесс
работы описан в [AGENTS.md](../AGENTS.md), выбор задач — в
[roadmap](product_roadmap.md). Шаблон подходит и для приложения, и для документации.

## Запрос

```text
Выполни одну задачу в solfege_app по AGENTS.md.

Задача: <ID из roadmap или конкретное описание>.
Результат для пользователя: <что станет работать или понятнее>.
Сценарий приёмки: <действия и ожидаемый результат>.
Область изменений: <модули / документы / инструменты разработки>.
Ограничения: <что не менять; нужны ли живые сервисы>.
Git: <локально либо разрешённые коммит / push / PR>.
```

Необязательно заполнять все поля дословно. Агент восстанавливает понятные границы
из запроса и уже согласованных решений; спрашивает только о существенном пробеле.
Для работы с уроками или практикой используется
[руководство по учебной программе](curriculum/README.md).

## Пример задачи на аудит

```text
Проверь APP-01 из roadmap только на чтение.
Объясни, почему пройденный урок может не открывать следующий.
Покажи соответствующие места в коде и опиши путь пользователя через основной экран.
Не меняй приложение, документы, ветки или PR.
```

Промпт не хранит список дефектов, архитектуру, правила разработки или копию учебных
требований. Их изменение не требует переписывать шаблон запроса.
